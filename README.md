# Kenes AI

В репозитории две части.

- `index.html` — лендинг агентства (реклама в ChatGPT, AEO, ИИ-агент).
- `aiintel/` — исследовательский прототип AI Intelligence: измеряет, как часто ИИ-системы называют компании в ответах на вопросы покупателей.

## AI Intelligence: прототип

Задаёт список вопросов нескольким ИИ, сохраняет ответы в базу, находит упоминания компаний и ссылки на источники, собирает HTML-отчёт.

Нужен только Python 3.10+, сторонних пакетов нет.

### Проверить без ключей

```bash
python3 -m aiintel demo studies/real_estate_kz.json
```

Отчёт появится в `reports/demo.html`. Ответы в этом режиме выдумывает заглушка, цифры ничего не значат.

### Настоящий запуск

```bash
export OPENAI_API_KEY=...
export GEMINI_API_KEY=...
export PERPLEXITY_API_KEY=...
python3 -m aiintel run studies/real_estate_kz.json --out reports/real_estate.html
```

Можно взять часть провайдеров и вопросов: `--providers openai --limit 5`.
Отчёт для другой компании из списка: `python3 -m aiintel report studies/real_estate_kz.json --client "Bazis-A"`.
Список запусков: `python3 -m aiintel runs`.

Модели задаются переменными `OPENAI_MODEL`, `GEMINI_MODEL`, `PERPLEXITY_MODEL`. Значения по умолчанию в `aiintel/providers.py` могли устареть — проверьте перед запуском.

### Что считается

- **AI Visibility Score** — доля ответов, где компания названа.
- **Средняя позиция** — какой по счёту компанию называют в ответе.
- **Доля голоса** — доля от всех упоминаний отслеживаемых компаний.
- **Ссылки на свой сайт** — в скольких ответах ИИ сослался на сайт компании.
- **Где компанию не называют** — вопросы, где есть конкуренты, а клиента нет.
- **Источники** — сайты, на которые ссылаются ИИ.
- Разбивка по ИИ-системам и история по запускам.

### Исследование

Файл `studies/real_estate_kz.json`: 5 застройщиков и 40 вопросов (30 на русском, 10 на казахском). Чтобы добавить отрасль, скопируйте файл и замените компании и вопросы. Домены компаний нужно проверить: по ним считаются ссылки на собственный сайт.

### База данных

SQLite в `data/aiintel.db`. Таблицы повторяют сущности из концепции: `companies`, `prompts`, `responses`, `mentions`, `citations`, `sources`, `visibility_history`, плюс `runs`. Конкуренты — это остальные компании того же исследования.

### Чего пока нет

- Тональности (как ИИ описывает компанию) и автоматических рекомендаций.
- Компаний вне списка: если ИИ назвал застройщика, которого нет в файле, он не учитывается.
- Панели управления, расписания, Postgres. Это следующий этап после первого настоящего отчёта.

## Körin: приложение и сервер

- `korin/` — сайт продукта, `korin/app/` — кабинет. Без сервера кабинет работает в демо-режиме на условных цифрах.
- `server/app.py` — сервер без сторонних пакетов. Три адреса: `/api/site-audit` (настоящая проверка сайта: robots.txt для ботов нейросетей и главная страница), `/api/check` (опрос нейросети по вопросам) и `/api/agent` (ИИ-агенты). Два последних требуют `OPENAI_API_KEY` с положительным балансом.

Запуск:

```bash
PORT=8000 KORIN_ORIGINS=https://kenesai.asia python3 -m server.app
```

Чтобы кабинет ходил на сервер, впишите его адрес в `const API` в начале скрипта `korin/app/index.html`.
