Это не ключевые слова, а описание продукта и клиента для системы.

## Риски

- В заголовках стоит слово «ChatGPT». Модерация может не пропустить чужой товарный знак. Запасные заголовки без него: «Реклама в нейросетях под ключ», «Ваш бизнес — под ответом ИИ».
